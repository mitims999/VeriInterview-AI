# Datasets

## Synthetic project fixtures (used, committed)

`data/synthetic/*.json`, generated by `scripts/generate_fixtures.py`:

1. `genuine.json` — Genuine Strong
2. `genuine_weak.json` — Genuine Weak
3. `ai_assisted.json` — AI-assisted Simulation
4. `deepfake.json` — Deepfake / Identity Simulation
5. `nervous_genuine.json` — Nervous Genuine Candidate

All candidate names, resumes, transcripts and signal values are entirely fabricated for
this hackathon prototype. No real biometric or personal data is used anywhere in the system.

## Public datasets referenced for future calibration (not bundled, not required to run the demo)

- **LFW** (Labeled Faces in the Wild) — face verification sanity-check for InsightFace, when integrated for real.
- **RAVDESS** (https://zenodo.org/records/1188976) — prosody/pitch/loudness validation for openSMILE.
- **CREMA-D** (https://github.com/CheyneyComputerScience/CREMA-D) — auxiliary prosody validation.
- **LRS2/LRS3** — optional SyncNet re-validation set.

None of these are downloaded or required by this repository; they are named here per the
Build Spec Section 5.1 for teams that later wire in the real adapters and want to validate
them against public benchmarks before trusting them on live interview data.
